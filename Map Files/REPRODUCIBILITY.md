Low Food Access by State Map, Reproducibility Notes:
Timothy Donkin (300567328)

This map (Map.Rmd) requires a licensed ArcGIS Pro installation with
the R-ArcGIS bridge (arcgisbinding) configured, since it reads state
boundary geometry through arc.open(). The ArcGIS Pro project and
geodatabase (Map for EDA/) are included in this folder, so the
boundary layer, including manual edits repositioning Alaska, Hawaii,
and the crowded Northeast states, does not need to be re-sourced from
Living Atlas.

Requirements to run:
- R 4.4+
- ArcGIS Pro, with R-ArcGIS bridge configured
  (Project > Options > Geoprocessing > R-ArcGIS Support)
- R packages: arcgisbinding, dplyr, classInt, ggplot2, ggrepel, sf
- food_access_clean_2019_M.csv (same cleaned dataset used in the main
  group report), same folder as Map.Rmd
- Map for EDA/ (ArcGIS Pro project + geodatabase), same folder as
  Map.Rmd, included in this repo

Paths in Map.Rmd are relative to the Rmd file's own location. Knitting
the file sets this automatically; running chunks interactively may
require setting the working directory manually first
(setwd() to this folder, or use an RStudio Project rooted here).

Output: low_access_by_state_map.pdf

For the group report, the finished PDF is provided directly rather
than regenerated by other members, since the ArcGIS Pro dependency
isn't practical for the whole group to set up.
